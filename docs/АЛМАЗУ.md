## 1. Что это
Госзаказ через Zhambyl Hub: платформа против мошенников для жителей Жамбылской области всех возрастов. Пилот по области, при успехе — контракт на следующий год.
**Дедлайн сдачи: 18.11.2026, 23:59.**

- Прод: https://aldanba.vercel.app
- Админка с отчётами: https://aldanba.vercel.app/admin
- Референс, на который смотрел заказчик: https://saq-bol.kz (квест АФМ, 5 миссий). У нас 14 видов мошенничества.

## 2. Что уже сделано и работает
- **14 уроков, 6 уровней.** Урок — анимированный «мультик» на экране телефона: звонок, SMS, чат, сайт, объявление, банк, персонажи. Плюс ИИ-озвучка и субтитры.
- **Языки:** казахский по умолчанию и русский. Озвучено 458 из 460 фраз.
- **Тесты:** после урока 2 вопроса с озвучкой. Уровни открываются по порядку. Итоговый тест — 14 вопросов, зачёт от 10. Сертификат PNG с именем.
- **Вход:** язык → имя → возраст → район. Без паролей и SMS.
- **Админка:** цифры, районы, возраст, уроки, дни, фильтры, выгрузка в Excel (CSV).
- **Нагрузка проверена на проде:** 876 запросов/с, 0 ошибок. Отчёт по 9 тыс. людей — 0,6 с.
- **Законы РК:**
  - имя на сервер не отправляется — база обезличенная;
  - казахский по умолчанию;
  - без брендов банков и госорганов.

  Подробно — в `brief.md` и `ЖУРНАЛ.md`.

## 3. Что осталось сделать (по важности)
1. ✅ **Трафик решён:** аудио идёт с бесплатного CDN jsDelivr из публичного репо (`NEXT_PUBLIC_AUDIO_BASE=https://cdn.jsdelivr.net/gh/zxcllxc/aldanba@master/public/audio` в Vercel). Если CDN не ответит, плеер сам берёт файл с Vercel (`src/lib/voice.ts`). Новые mp3 на jsDelivr `@master` могут появиться с задержкой до 12 часов — это не страшно, всё это время работает запасной путь.
2. ✅ **Доступ:** см. раздел 4.
3. **Носитель казахского** — пройти уроки на казахском, поправить неестественные фразы в `src/content/lessons/*.ts`, потом `npm run tts` и деплой.
4. **2 неозвученные реплики** (сервис Microsoft отказывается их озвучивать — фильтр контента): урок 6 «Мама, я попал в беду…» и урок 14 «Любимая, я в больнице…», обе на русском. Варианты:
   - перефразировать и запустить `npm run tts`;
   - записать голос вручную в mp3 и положить файлом с тем же именем. Имя файла: `src/lib/audio-key.ts`, функция `audioKey("ru", "s", текст)`.
5. **Согласовать с Zhambyl Hub:** кто «оператор» в `/privacy` и на сертификате. «При поддержке …» — только с письменного согласия.
6. **Проверить на реальном старом Android** — пока проверено только в эмуляции 375 px.
7. **Мелочь:** в `public/audio/` лежат 2 мусорных файла `*.part`, их можно удалить.

## 4. Доступы и секреты
**Репозиторий (публичный): https://github.com/zxcllxc/aldanba.** Тебе (`almaz-svg`) отправлено приглашение с правом записи — прими его на GitHub или из письма. **Секретов в репозитории нет и быть не должно** — репо видят все.

**Как деплоить:** репо подключено к Vercel-проекту `aldanba` (аккаунт Дони).
- `git push` в **`master`** → Vercel сам собирает и выкатывает на https://aldanba.vercel.app (1–2 мин).
- Пуш в любую другую ветку → отдельная preview-ссылка, прод не трогается. Проверяй там, потом мерджи в `master`.
- Статус сборки — в GitHub, у коммита (галочка или крестик Vercel), ссылка на лог там же.
- Ключи базы и пароль админки лежат в Vercel, для деплоя они тебе не нужны.

**Пароль админки** (`ADMIN_PASSWORD`) Дони передаст лично, не в общий чат.

**Локальный запуск с базой:** нужен `DATABASE_URL`. Попроси у Дони отдельно, лично, или подними свою бесплатную Neon для разработки (`scripts/schema.sql` создаст таблицы). Без базы сайт и уроки работают, не сохраняется только прогресс на сервере.

Имена переменных — в `.env.example`.

## 5. Как устроено
| Что | Где |
|---|---|
| Стек | Next.js 16.4 (App Router, `cacheComponents`), React 19, Tailwind 4, TypeScript, Neon Postgres (`@neondatabase/serverless`), Vercel (функции в fra1, `vercel.json`) |
| Тексты уроков | `src/content/lessons/l01.ts … l14.ts`, формат — `src/content/types.ts`, уровни — `src/content/levels.ts` |
| Тексты интерфейса, районы, возрасты | `src/lib/i18n.ts` |
| Сцены-«мультики» | `src/components/Stage.tsx` |
| Плеер урока, тест | `src/components/LessonView.tsx`, `src/components/Quiz.tsx` |
| Озвучка в браузере | `src/lib/voice.ts` (если звук не загрузился — ждёт по длине текста, урок не зависает) |
| Профиль и прогресс на телефоне | `src/lib/store.ts` (localStorage; очередь событий переживает обрыв сети) |
| API | `src/app/api/track/route.ts` (регистрация и результаты, строгая валидация), `src/app/api/admin/stats`, `src/app/api/admin/export` |
| База | `scripts/schema.sql`: `participants` (uuid, lang, age_group, district) и `progress` (участник, урок, баллы). Схема применяется при каждом `npm run build` |
| Страницы | `/` вход, `/learn` карта уроков, `/lesson/[id]`, `/final`, `/certificate`, `/privacy`, `/admin` |
| Дизайн | синий `#0e5fa8` + золото `#f2b705`, шрифт Rubik, сова Үкі (`src/components/Brand.tsx`), орнамент «қошқар мүйіз» |

**Главное правило: имя пользователя НИКОГДА не отправлять на сервер** (Закон РК № 94-V). Если заказчик захочет ФИО, телефон или ИИН, это уже персональные данные. Тогда нужна база на сервере в РК и согласие (для детей — родителей).

## 6. Команды
```bash
git clone https://github.com/zxcllxc/aldanba && cd aldanba
npm install
# для работы с базой локально: .env.local со значениями из .env.example (см. раздел 4)
npm run dev                      # http://localhost:3000
npm run build                    # применяет схему БД и собирает
git push origin master           # деплой на прод (Vercel сам соберёт)
python -m pip install edge-tts   # один раз, для озвучки
npm run tts                      # озвучить новые/изменённые фразы (старые удалятся сами)
node scripts/load-test.mjs https://aldanba.vercel.app 150 30            # нагрузочный тест
node --env-file=.env.local scripts/load-test.mjs --cleanup                # удалить тестовых пользователей
```
Уже настроено в Vercel у Дони: база Neon, `ADMIN_PASSWORD`, `NEXT_PUBLIC_AUDIO_BASE`, Firewall (rate limit 300 запросов/мин с IP на `/api/track`), регион функций fra1.

## 7. Подводные камни
- **Next.js 16 отличается от того, что ты знаешь.** Перед правками смотри доки в `node_modules/next/dist/docs/` (см. `AGENTS.md`). Например, `params` в динамических страницах нужно оборачивать в `<Suspense>`.
- **Озвучка (edge-tts):**
  - бесплатная, но голос `ru-RU-DmitryNeural` иногда сбоит на длинных фразах — скрипт сам повторяет и режет фразу на предложения;
  - имя mp3 — хеш текста: любая правка текста = новый файл, поэтому после правок всегда запускай `npm run tts`.
- **Hobby:** доступно только 1 правило rate limit.
- **Выгрузку «по каждому участнику» убрали намеренно:** на 30 тыс.+ строк упираемся в лимит ответа функции 4,5 МБ. Если нужна — только с фильтром по району или потоковой отдачей.
- Сертификат проверяется на телефоне, а не на сервере. В отчёте админки сертификат засчитывается, только если пройдены все 14 уроков и итоговый тест.
