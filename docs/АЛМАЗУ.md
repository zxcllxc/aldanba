Госзаказ через Zhambyl Hub: платформа против мошенников для жителей Жамбылской области всех возрастов. Пилот по области, при успехе — контракт на следующий год.
**Дедлайн сдачи: 18.11.2026, 23:59.**

- Прод: https://aldanba.vercel.app
- Админка с отчётами: https://aldanba.vercel.app/admin
- Референс, на который смотрел заказчик: https://saq-bol.kz (квест АФМ, 5 миссий). У нас 14 видов мошенничества.

## 2. Что уже сделано и работает
- **14 уроков, 6 уровней.** Урок — анимированный «мультик» на экране телефона: звонок, SMS, чат, сайт, объявление, банк, персонажи. Плюс ИИ-озвучка и субтитры.
- **Языки:** казахский по умолчанию и русский. Озвучено 458 из 460 фраз.
- **Тесты:** после урока 2 вопроса с озвучкой. Уровни открываются по порядку. Итоговый тест — 14 вопросов, зачёт от 10. Сертификат PNG с именем.
- **Вход:** язык → имя → возраст → район. Без паролей и SMS.
- **Админка:** цифры, районы, возраст, уроки, дни, фильтры, выгрузка в Excel (CSV).
- **Нагрузка проверена на проде:** 876 запросов/с, 0 ошибок. Отчёт по 9 тыс. людей — 0,6 с.
- **Законы РК:**
  - имя на сервер не отправляется — база обезличенная;
  - казахский по умолчанию;
  - без брендов банков и госорганов.

  Подробно — в `brief.md` и `ЖУРНАЛ.md`.

## 3. Что осталось сделать (по важности)
1. **Хостинг и трафик (решить до запуска).** Vercel сейчас на бесплатном Hobby: 100 ГБ/мес ≈ 11 тыс. полных прохождений, и Hobby только для некоммерческих проектов. Варианты:
   - **Vercel Pro, $20/мес.** Ничего менять не надо.
   - **Бесплатно:** создать публичный GitHub-репозиторий только с аудио (`public/audio/*.mp3`) и прописать в Vercel переменную `NEXT_PUBLIC_AUDIO_BASE=https://cdn.jsdelivr.net/gh/<owner>/<repo>@main`. Код уже умеет брать звук с CDN и сам откатываться на Vercel, если CDN не ответил (`src/lib/voice.ts`).
2. **Доступ к проекту** (см. раздел 4).
3. **Носитель казахского** — пройти уроки на казахском, поправить неестественные фразы в `src/content/lessons/*.ts`, потом `npm run tts` и деплой.
4. **2 неозвученные реплики** (сервис Microsoft отказывается их озвучивать — фильтр контента): урок 6 «Мама, я попал в беду…» и урок 14 «Любимая, я в больнице…», обе на русском. Варианты:
   - перефразировать и запустить `npm run tts`;
   - записать голос вручную в mp3 и положить файлом с тем же именем. Имя файла: `src/lib/audio-key.ts`, функция `audioKey("ru", "s", текст)`.
5. **Согласовать с Zhambyl Hub:** кто «оператор» в `/privacy` и на сертификате. «При поддержке …» — только с письменного согласия.
6. **Проверить на реальном старом Android** — пока проверено только в эмуляции 375 px.
7. **Мелочь:** в `public/audio/` лежат 2 мусорных файла `*.part`, их можно удалить.

## 4. Доступы и секреты
**Секретов в этом архиве нет** — файл `.env.local` специально не включён.
- Vercel-проект `aldanba` и база Neon сейчас в аккаунте Дони (команда `zxcllxc-projects`, тариф Hobby). На Hobby нельзя добавить второго участника, поэтому есть 3 варианта:
  - **(а) Свой Vercel + своя Neon.** База пока пустая, данные не теряются. 10 минут, шаги в разделе 6.
  - **(б) Дони переносит проект на твой аккаунт:** Vercel → Settings → Transfer. Neon-интеграцию после этого нужно проверить.
  - **(в) Дони переходит на Pro и приглашает тебя.**
- **Пароль админки** — переменная `ADMIN_PASSWORD`. Если остаёшься на проекте Дони, он передаст пароль лично (не в общий чат). Если поднимаешь свой (вариант а) — придумай новый, от 14 случайных символов.
- **Переменные окружения:** имена — в `.env.example`. `DATABASE_URL` / `DATABASE_URL_UNPOOLED` выдаёт интеграция Neon в Vercel автоматически.

## 6. Команды
```bash
npm install
# локально нужен .env.local: `vercel link` + `vercel env pull .env.local` (или свои значения из .env.example)
npm run dev                      # http://localhost:3000
npm run build                    # применяет схему БД и собирает
vercel deploy --prod             # деплой
python -m pip install edge-tts   # один раз, для озвучки
npm run tts                      # озвучить новые/изменённые фразы (старые удалятся сами)
node scripts/load-test.mjs https://aldanba.vercel.app 150 30            # нагрузочный тест
node --env-file=.env.local scripts/load-test.mjs --cleanup                # удалить тестовых пользователей
```
**Свой Vercel с нуля (вариант а):**
1. `vercel link` (новый проект).
2. `vercel integration add neon`.
3. `vercel env add ADMIN_PASSWORD` (для production/preview/development).
4. `vercel deploy --prod`.
5. Если нужно — Vercel Firewall: rate limit 300 запросов/мин с IP на `/api/track` (сейчас настроен у Дони).

## 7. Подводные камни
- **Next.js 16 отличается от того, что ты знаешь.** Перед правками смотри доки в `node_modules/next/dist/docs/` (см. `AGENTS.md`). Например, `params` в динамических страницах нужно оборачивать в `<Suspense>`.
- **Озвучка (edge-tts):**
  - бесплатная, но голос `ru-RU-DmitryNeural` иногда сбоит на длинных фразах — скрипт сам повторяет и режет фразу на предложения;
  - имя mp3 — хеш текста: любая правка текста = новый файл, поэтому после правок всегда запускай `npm run tts`.
- **Hobby:** доступно только 1 правило rate limit.
- **Выгрузку «по каждому участнику» убрали намеренно:** на 30 тыс.+ строк упираемся в лимит ответа функции 4,5 МБ. Если нужна — только с фильтром по району или потоковой отдачей.
- Сертификат проверяется на телефоне, а не на сервере. В отчёте админки сертификат засчитывается, только если пройдены все 14 уроков и итоговый тест.
