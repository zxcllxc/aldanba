# ТЗ: «Алданба!» — платформа против мошенников (Жамбылская область)

Заказ: государство через Zhambyl Hub, команда Дони + Алмаз. Пилот по области, при успехе — контракт на следующий год.
Дедлайн: **18.11.2026, 23:59**. Референс: saq-bol.kz (квест АФМ, 5 миссий). Нам нужно шире: все виды мошенничества.

## Для кого
Все жители области: школьники с 7 лет, взрослые, пожилые. Многие говорят по-казахски, многие с простыми Android-телефонами и слабым интернетом.

## Что должно быть (решения Дони 17.11)
1. **Языки:** казахский (по умолчанию) + русский, переключатель в один тап. Озвучка на обоих.
2. **Вход:** имя + возраст + район. Без пароля, без SMS. Устройство запоминает человека.
3. **Уроки — «видео» без текста:** анимированные сцены (звонок «из банка», SMS, чат, объявление) + ИИ-озвучка. Сделаны нами, без чужих авторских прав.
4. **Тесты-уровни:** после каждого урока 2–3 вопроса «мошенник или нет?» с большими кнопками и озвучкой. Уровни открываются по порядку. В конце — итоговый тест и сертификат.
5. **Отчёты:** админ-панель по паролю: сколько людей, по районам, по возрасту, кто какой урок прошёл, средние баллы, сертификаты. Выгрузка в Excel (CSV) в любой момент.
6. **Нагрузка:** десятки тысяч людей. Должно быстро работать на слабом телефоне и 3G.

## Соответствие законам РК (обязательно)
- **Закон РК «О персональных данных и их защите» № 94-V:** на сервер **не отправляем имя**. Имя хранится только на устройстве (для сертификата). На сервер уходят: случайный ID устройства, возрастная группа, район, язык, прогресс. Это обезличенная статистика, по ней нельзя установить человека → требование хранить ПД в базах на территории РК не затрагивается. Короткое уведомление об этом на экране входа + страница «Конфиденциальность».
- **Закон «О языках в РК»:** государственный язык — по умолчанию и в полном объёме, русский — равноценно.
- **Товарные знаки и госсимволика:** без логотипов реальных банков, маркетплейсов и госорганов. Банки в сценах — вымышленные («QazBank»), органы упоминаются только словами в речи мошенника как пример обмана. Платформа не выдаёт себя за госорган; «при поддержке …» — только после письменного согласования.
- **Номера и ссылки в примерах** — замаскированные или вымышленные (`+7 7•• ••• 13 13`, `kaz-post-pay.top`), чтобы не задеть реальных людей.
- **Контент:** только распознавание и защита, никаких инструкций «как обмануть».
- **Дети:** ПД не собираем → отдельное согласие родителей не нужно.
- Телефоны помощи — только проверенные: 102 (полиция), номер банка с обратной стороны карты.

## Архитектура (решено)
- Next.js на Vercel: страницы статические, отдаются с CDN → держат любую нагрузку.
- Сцены уроков — HTML/CSS-анимация в браузере + mp3-озвучка (edge-tts, голоса kk-KZ Aigul/Daulet, ru-RU Svetlana/Dmitry). Урок весит сотни КБ, а не десятки МБ, как видео.
- База: Postgres (Neon через Vercel). Запросы к API — только при входе и при завершении урока.
- Админка: `/admin`, пароль в переменной окружения.

## Готово, когда
- Человек с телефона за ≤30 секунд входит и запускает первый урок.
- Все 14 уроков проигрываются со звуком на обоих языках, тесты засчитываются.
- Админ видит отчёт и скачивает CSV.
- Нагрузочный тест API и база выдерживают пик.
- Проверено на ширине 375px, консоль без ошибок, продакшен-ссылка открывается.
